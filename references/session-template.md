# Small reusable output shapes

Adapt these to the task. Do not generate every template for every lesson.

## First session

**Target:** By the end, you can [observable action].

**Scope:** [Supplied course objective and page/slide, or provisional topic.]  
**Model:** [Short explanation, boundaries, and a source.]  
**Worked example:** [Reasoned steps, units where relevant.]  
**Your turn:** [One question; wait for the learner.]  
**After the attempt:** [Specific feedback, assistance used, changed application.]  
**Resume:** “Continue [target]; last time [actual observation]. Start with [fresh retrieval].”

## Course study pack

1. Scope map: assessed objective, verified page/slide/section, practice task, coverage gap.
2. Compact explanation and worked examples, with source links.
3. Original practice in the expected format; clear instructions and space to reason.
4. Separate answer key: answer, reasoning/rubric, misconception, source, partial-credit basis if appropriate.
5. Review queue: target, next suggested check, rationale; indicate that it is not a scheduled notification.

Mark generated practice as original. A coverage map describes material covered, not the learner's proficiency.

## Minimal private session record

Save only when requested/agreed, in the learner's chosen location. Do not add it to this public skill.

```text
Target:
Source and course scope:
Attempt date and time zone:
Question/task:
Response summary:
Assistance: independent | hinted | cued | answer revealed
Result: correct | partly correct | incorrect | unscored
Rubric/reason:
Observed state and actual delay, if any:
Misconception/uncertainty:
Next suggested retrieval:
```

Use a fictional learner only in examples and label it as simulated. Keep actual learner observations distinct from tutor-generated demonstrations and software QA.

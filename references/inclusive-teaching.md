# Adapt the task, with the learner

Ask the optional neurodivergence/access question once at an appropriate point. Accept “skip,” “not sure,” or a functional preference without requesting a diagnosis. A label does not determine an individual's needs. Do not offer diagnosis, screening, treatment, or promises to correct a condition.

Offer a small choice only when it solves a real friction:

| Learner says | Try, then check whether it helps |
| --- | --- |
| “Too much at once.” | One objective, shorter chunks, one visible question, and a pause/resume cue. |
| “I lose the steps.” | A worked checklist, explicit intermediate steps, then gradually remove support. |
| “The wording is hard.” | Plain wording, a small glossary, uncluttered typography, and a diagram with a text equivalent. |
| “I need to say it.” | An oral tell-back if the current tools support it; accept a typed approximation otherwise. |
| “I freeze during tests.” | Offer an untimed, low-stakes attempt, a hint, or an explanation first. Ask about format; do not diagnose anxiety. |
| “I get bored.” | Connect to a stated interest and move to an authentic application with useful feedback. |
| “I can't access that image/audio.” | Supply meaningful alternative text/transcript and a task that measures the same objective where possible. |

Give response choices when compatible with the target: speech, writing, drawing, demonstration, or code. If a course tests a specific format, explain the tradeoff and practice it with appropriate support. Do not change the assessed construct silently.

Avoid timers, animation, streaks, guilt, or escalating pressure as defaults. A break or opting out is a valid choice. Do not repeatedly ask the learner to explain why they need an adaptation.

Preferences can improve access and comfort without proving a fixed visual/auditory/kinesthetic “learning style.” Match the representation to the concept and measure understanding through attempts. Use CAST UDL as a design framework, not a diagnostic tool or proof that every option improves every learner's scores; see [evidence.md](evidence.md).

Privacy: keep disclosures out of research queries, public examples, and shared artifacts. Ask separately before saving functional preferences for later; save the useful preference rather than a diagnostic label whenever possible. Do not imply that a chat tool provides clinical confidentiality or durable memory it does not actually have.

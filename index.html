01 How it routes

One entry point. Nine specialists.

Ask in plain language. The router reads what you are after — understanding, a lab, cards, a plan — and hands the request, with your context, to the skill built for it. Skills hand off to each other, so a course can end in a printable practice test and high-stakes material can pass through verify before it ships.

You ask
Teach me limiting reactants. Exam is Friday.
Router

myelinate

Reads the goal, picks the skill, passes along your context.

  1. teachLearns how you learn; builds and teaches your course.
  2. tutorLive teaching in chat or voice, one step at a time.
  3. labBuilds interactive simulations as web pages.
  4. printPrintable tests, answer keys, diagrams and worksheets.
  5. flashcardsCards ready for Quizlet, Anki or Obsidian.
  6. memory-hooksResearch-backed mnemonics for what won’t stick.
  7. study-planWorks back from the exam: spacing, relearning, sleep.
  8. find-mediaDiagrams, photos and videos, with licensing noted.
  9. verifyAdversarial review before high-stakes material ships.

Each skill is a Markdown file you can read in full. Nothing runs in the background, and nothing is sent anywhere your assistant does not already send it.

02 What it does differently

Built on how people actually learn, not on how chatbots like to talk.

The same AI can help or hurt. What decides it is behavior: who does the thinking, how answers are revealed, and whether the facts were checked first.

−17%

Exam scores for high-school students who practiced with an answer-giving GPT-4 chat, compared with students who had no AI. A version with tutoring guardrails largely avoided the harm.

Bastani et al., PNAS 2025
≈0.6 SD

Larger learning gains, in less time, for an AI tutor built on pre-worked solutions and step-by-step reveals, compared with an in-class active-learning lesson (Harvard physics, N = 194).

Kestin et al., Scientific Reports 2025

These studies tested specific tutors in specific courses. They shaped Myelinate’s design; they did not measure Myelinate, and its own effect on learning has not been established.

i.

Predict before you see

You commit to a guess before the explanation. Even a wrong guess gives the answer somewhere to land.

Richland, Kornell & Kao, J. Exp. Psychol.: Applied 2009
ii.

Retrieval, not rereading

Sessions close by pulling ideas back from memory, mixed with look-alikes, instead of a tidy summary to skim.

Roediger & Karpicke, Psychol. Sci. 2006; Dunlosky et al., PSPI 2013
iii.

One step at a time

The tutor never solves your problem on the first turn. It reveals a step, asks for the next, and stays short.

Bastani et al., PNAS 2025
iv.

Feedback that explains

A wrong answer gets a hint first, then the specific gap and why, then a fresh problem to use it on.

Butler & Roediger, Mem. Cognit. 2008
v.

Worked examples, then fading

New ideas start from a worked parallel example. As you succeed, the worked steps drop away until you solve alone.

Renkl & Atkinson, Educ. Psychol. 2003
vi.

Spaced relearning

Study plans work back from the exam date, revisit material across days, and protect the sleep that consolidation needs.

Cepeda et al., Psychol. Bull. 2006; Dunlosky et al., PSPI 2013
vii.

Honest, not agreeable

It won’t confirm a wrong answer, inflate praise, or cave when you push back on a correct correction. It changes its mind on evidence.

Sharma et al., arXiv:2310.13548 2023
viii.

Remembers how you learn

The first session asks a few questions about pace, chunk size and what’s hard. Later sessions start from that profile.

Design choice, not a study finding
ix.

Reviewed before it ships

Answer keys are worked before tutoring starts, and high-stakes material gets an adversarial review for accuracy and currency.

Kestin et al., Sci. Rep. 2025

04 Install

Add it to the assistant you already use.

Myelinate is a folder of Markdown skills. No packages, keys or accounts beyond your assistant’s own.

Claude apps

  1. Download the repository as a ZIP.
  2. Upload it where Claude lets you add a skill (in Settings, under Skills).
  3. Start a chat with Use myelinate to…

No skill uploads where you are? Paste SKILL.md into a project’s instructions instead.

Claude Code macOS · Linux

Terminal
git clone https://github.com/baney75/myelinate.git
mkdir -p ~/.claude/skills
ln -s "$PWD/myelinate" ~/.claude/skills/myelinate

Run the link command from the directory that holds the clone, then start a new session.

Codex macOS · Linux

Terminal
git clone https://github.com/baney75/myelinate.git
mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
ln -s "$PWD/myelinate" "${CODEX_HOME:-$HOME/.codex}/skills/myelinate"

If a myelinate skill already exists, inspect it before replacing anything. On Windows, copy the folder into your skills directory. Then use $myelinate.

Other assistants

If it can open links, paste the line above. Otherwise use its skill importer on this folder, or give it SKILL.md as instructions, with the skills/ and references/ folders for the full suite.

Browsing and file reading let it research current sources and read your course files; without them, it says what it could not check. Compatibility has not been tested in every assistant.

05 Guardrails

Honest about you, honest about itself.

Never labels learners

It asks how you learn — pace, chunk size, what’s hard. You may share a learning condition if you choose; it is never required, and it never guesses one.

Honest progress

Independent, hinted and revealed answers are recorded as different things. No invented mastery scores.

Honest, not agreeable

No confirming wrong answers, no inflated praise, no caving to pushback on a correct correction. Evidence changes its mind; pressure doesn’t.

A profile you control

What it learns about how you learn lives in your assistant’s memory or a profile file you keep. Course files and personal details stay out of public outputs.

Sources and limits, shown

Claims come with sources, and it says when it is unsure or could not check something.

No pretend reminders

A suggested review time is a suggestion. It only schedules something when your assistant can actually schedule it.

No guaranteed memory

It cannot force permanent memory or promise a grade, and it will not claim to.

About the name. Myelin insulates nerve fibers so signals jump from node to node. Practice strengthens the pathways you use. Here it is a metaphor, not a mechanism: no prompt changes your myelin.
